# PavSim

[English](README.md) | **Русский**

PavSim — локальное приложение для визуального моделирования динамических систем и подбора параметров. Общая схема передаёт структурированные данные между блоками, а внутри эксперимента динамическая система работает со скалярными сигналами.

## Запуск

Нужны Python 3.12 и современный браузер. Python-часть использует стандартную библиотеку.

```bash
python3 -m venv .venv
.venv/bin/python -m shell.server --host 127.0.0.1 --port 8881
```

Откройте http://127.0.0.1:8881/. Сервер рассчитан на локальное использование и не предоставляет аутентификацию. Язык переключается кнопкой EN/RU.

## Первые шаги

1. Разместите на общем полотне «Запускатор», «Константа (структуры)» и «Вывод результата».
2. Соедините запускатор со входом константы, а выход константы — с выводом результата. Значение и номер потока задаются в параметрах блоков: выделите блок и нажмите F2 или «Параметры».
3. Нажмите «Запуск». Номер над блоками показывает проходящий поток. Сохранить и открыть схему можно кнопками в верхней панели.

Для подбора соедините выходы p1/p2/p3 оптимизатора с соответствующими входами эксперимента, а выход J эксперимента — с входом J оптимизатора. Подключите запускатор ко входу start оптимизатора. Двойным нажатием откройте эксперимент и создайте внутреннюю динамическую схему; параметры времени и решателя задаются в настройках эксперимента. Журнал оптимизатора открывается двойным нажатием, его параметры — через F2.

**Порядок проводов имеет значение:** сигналы отправляются по номерам проводов в порядке их подключения, с обходом в глубину. Для графика во время подбора подключайте его до ветки, продолжающей расчёт: p1 и p2 — сначала к графику, затем к эксперименту; J — сначала к графику, затем к оптимизатору; запуск — сначала к сбросу графика, затем к оптимизатору.

Каждый запускатор задаёт номер потока. Независимым оптимизаторам назначайте разные номера и отдельные эксперименты. Эксперимент не объединяет входы разных потоков. Кнопка «Стоп» завершает работу сессии и освобождает её ресурсы.

## Проверки

Для полного набора дополнительно нужен Node.js:

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B -m unittest discover -s tests -v
```

## Ограничения

- Численное моделирование использует фиксированный шаг и методы RK4 или Euler. Настройки задаются в эксперименте.
- Схемы со старыми блоками расчёта не поддерживаются новой версией; для них используйте прежнюю версию PavSim.
- Схема сохраняется в JSON; результаты и временные объекты сессии при сохранении не записываются.
- Пользовательские численные блоки на Python выполняются как доверенный код.

Устройство блоков и порядок доставки сигналов описаны в [документе об интерфейсах](docs/block-interface.md), работа процесса — в [описании сессии](docs/session-process.md).
