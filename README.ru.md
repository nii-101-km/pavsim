# PavSim 0.1.1

[English](README.md) | **Русский**

**Parametric Analysis & Visual Simulation**

PavSim — локальное приложение для визуального моделирования динамических
систем, оценки переходных процессов и подбора параметров. Интерфейс работает
в браузере; моделирование выполняет Python-сервер.

## Возможности

- 61 тип блока: источники, арифметика, динамические и дискретные элементы,
  логика, задержки, регуляторы, визуализация и оптимизация.
- Численное моделирование с фиксированным шагом: RK4 и Euler.
- Скалярные порты, разветвление сигнала и независимые выходы блоков.
- П-регулятор через Усилитель; ПИ, ПД и ПИД с отдельными входами коэффициентов.
  Производная ПИД фильтруется, filter_tau должна быть положительной.
- Подсистемы с In1/Out1 и независимые Эксперименты с локальными t_end, h и method.
- Подбор до трёх параметров: покоординатный поиск, Нелдер–Мид, численный
  градиентный метод, Хук–Дживс и тяжёлый шарик Поляка.
- Цели: IAE, ISE, время регулирования, перерегулирование и колебательность.
- Графики одного сигнала, 2–4 серий, XY и XY с оценкой «шаг | J».
- Сохранение схем, параметров блоков, внутренних схем и маршрутов связей в JSON.

## Установка и запуск

Проверено на Linux x86_64, CPython 3.12.3. Python-часть использует только
стандартную библиотеку. Сторонние Python-пакеты устанавливать не требуется.
Минимальная поддерживаемая версия Python пока не подтверждена отдельной проверкой.
Нужен современный браузер.

Из каталога проекта:

```bash
python3 -m venv .venv
.venv/bin/python xcos_mini/server.py --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000/. Сервер предназначен для локального
использования и не содержит аутентификации. Встроенные модули xcos_mini и
имена типов блоков сохранены для совместимости.

## Язык интерфейса

При первом открытии используется английский. Переключатель **EN/RU** в верхней
панели меняет язык без перезагрузки и потери модели или результатов.
Выбор сохраняется в localStorage и применяется также к окнам графиков.
Язык браузера не определяет язык приложения. Если хранилище недоступно,
переключение работает в текущей странице, но выбор не сохраняется.

## Минимальная схема

Ниже используются русские названия блоков; выберите **RU** в верхней панели.

1. Выберите «Константа» в библиотеке и кликните на поле. Двойным кликом
   откройте параметры и задайте value=1.
2. Разместите «Интегратор» и «График».
3. Соедините Константа → Интегратор → График: зажмите выходной красный
   порт, перетащите указатель на входной зелёный порт и отпустите.
4. Задайте t_end=1, h=0.01, RK4 и нажмите Run.
5. Откройте график двойным кликом или ссылкой результата. Ожидается y(t)=t.

Параметры выбранного блока также открываются кнопкой «Параметры» или F2.
Для сохранения задайте имя и нажмите Save. Для загрузки выберите имя и Load.

Примеры в examples/: ПИ-контур, ПИД с четырьмя входами, транспортная задержка,
блочный оптимизатор и рабочее поле независимого эксперимента. Чтобы открыть
пример через меню Load, скопируйте нужный JSON под новым именем в models/;
не заменяйте существующие пользовательские файлы.

## Эксперименты и оптимизация

Эксперимент получает p1/p2/p3, запускает внутреннюю схему с новыми начальными
состояниями и возвращает конечную J. Подключите выходы Оптимизатора к этим
входам, а J эксперимента — ко входу оптимизатора. Активные переменные и их
границы задаются галочками и полями. Неактивные параметры сохраняют значение.
Для Хука–Дживса доступны initial_step, pattern_step, shrink и tolerance
в строке key=value; key=value. По умолчанию случайная разведка выключена.

При наличии Эксперимента общие временные поля скрываются на внешнем полотне;
внутри отображаются локальные настройки этого эксперимента. Верхний Run
выполняет подбор, внутренний Run — только выбранный эксперимент.

## Ограничения

- Фиксированный шаг, без адаптивного решателя и отдельного решателя алгебраических петель.
- Временная сетка заканчивается точно на t_end: при необходимости последний шаг
  интегрирования укорачивается. Номинальный h и период дискретизации блоков сохраняются.
  z⁻¹ задерживает на один выходной отсчёт; у последнего интервала длительность может
  быть меньше h. Транспортная задержка продолжает измеряться в модельном времени.
- Нет поддержки .xcos, произвольных векторных сигналов и трёхмерных графиков.
  Внутренний тип graph_xyz обозначает XY с оценкой, а не 3D-график.
- Обычная Подсистема имеет один вход/выход; произвольная вложенность не реализована.
- Эксперименты выполняются последовательно. Вложенные эксперименты и оптимизаторы
  внутри эксперимента не поддерживаются.
- Графики относятся к запуску: сервер хранит последние пять наборов в памяти.
  Save сохраняет модель, а не историю результатов. Глобальные настройки обычного
  прогона не входят в JSON схемы; локальные настройки Эксперимента сохраняются.
- Производные и задержки требуют разумного выбора h; RK4 не гарантирует четвёртый
  порядок для дискретных событий и разрывных сигналов.
- Дополнительные Python-блоки — доверенный исполняемый код, без sandbox.
- Статические файлы ограничены реальным каталогом web/, включая проверку символьных
  ссылок. Аутентификации и сетевого многопользовательского режима нет.
