# Эксперименты и рабочее поле

В инструкции используются русские названия интерфейса: выберите **RU**
в верхней панели. Начиная с PavSim 0.1.1 по умолчанию выбран **EN**;
переключение языка не меняет идентификаторы и формат моделей.

Эксперимент — отдельный контейнер, обычная Подсистема сохраняет прежнюю
семантику общего времени. В Эксперименте свои t_end, h и method; настройка
сохраняется вместе с внутренней схемой в JSON.

Входы p1/p2/p3 — один полный набор параметров пробы. Внутри доступны
защищённые терминалы P1/P2/P3 и J. Сигнал итоговой оценки подключается к J,
например выход блока Целевая функция с IAE или ISE. Выход Эксперимента —
конечная скалярная J, доступная только после завершённого прогона.

Оптимизатор подключается выходами к параметрам Эксперимента, а на свой вход
получает его J. Поиск ничего не знает о регуляторе и о типе внутренней цели.
У каждой пробы новая модель и Engine: интеграторы, память, задержки,
накопители и случайные последовательности стартуют заново. Фиксированный
seed позволяет сравнивать параметры на одинаковом шумовом воздействии.
При ошибке расчёта успешная оценка не выдаётся: поиск учитывает неудачную
пробу, а единичный запуск возвращает ошибку.

Рабочее поле может содержать несколько экспериментов с разными часами и
методами. Независимые эксперименты выполняются последовательно; зависимости
от результатов других экспериментов разрешаются до запуска потребителя.
Цикл таких зависимостей отклоняется. Оптимизатор разрывает обратную связь J
при вычислении параметров — он выдаёт уже выбранный набор. Динамические
контуры рабочего поля помещаются внутрь экспериментов. На поле остаются
параметры, арифметические связи, оптимизаторы, эксперименты и графики проб.

Двойной клик открывает внутреннее полотно. Настройки доступны одноимённой
кнопкой; видимые поля t_end/h/method внутри относятся к данному эксперименту.
Run из внутреннего полотна выполняет только выбранный эксперимент с текущими
параметрами, без повторного подбора. Run с рабочего поля выполняет подбор
и итоговые прогоны. Внутри можно использовать обычную Подсистему. Вложенные
Эксперименты и Оптимизаторы внутри эксперимента пока не допускаются.

## Графики

Добавлены График 2/3/4 серий, XY и «XY с оценкой». Каждый вход записывается отдельно.
XY использует x/y как координаты. «XY с оценкой» подписывает точки как
«номер шага | ошибка», получая оценку с третьего входа J. Цветовой шкалы нет.
Перекрывающиеся подписи скрываются; при наведении видны шаг, оценка и координаты.
Оба XY-графика имеют поля x_range/y_range: например, 0:5; пустое поле —
автомасштаб. Параметры открываются выбором блока и кнопкой «Параметры» или F2.
Внутри эксперимента график серий имеет ось модельного времени.

Снаружи графики получают по точке на успешную рассчитанную пробу:
параметры оптимизатора — из набора данной пробы, J — из завершённого
эксперимента. Для маршрута подключите p1→x, p2→y и Эксперимент.J→J.
Маршрут показывает все проверенные наборы в порядке расчёта, включая
начальную пробу и варианты, которые не стали лучшими.

После Run есть прямые ссылки на графики. Данные графиков относятся к
конкретному запуску: сервер держит последние пять снимков в памяти;
перезапуск сервера очищает их. Save сохраняет схему, настройки и найденные
параметры, а не историю результатов. После загрузки нужно снова выполнить Run.

Пример: demo_experiment_workspace. Внутри — ПИ и апериодическое звено,
снаружи — оптимизатор, график трёх серий и XY-маршрут с подписями шага и J.
Локальные настройки: 10 / 0.02 / RK4. При лимите 40 проб начальная IAE
примерно 5.98 сокращается до 0.20. Отклик имеет 501 отсчёт, маршрут —
до 40 рассчитанных точек: повторные наборы берутся из кэша и не расходуют
новые расчёты. Это разные шкалы.

## Проверки

Проверены независимые настройки двух экспериментов, отдельный Run,
неизменность исходного JSON, свежие состояния, история задержки, повторяемый
шум, конечная скалярная J, пять алгоритмов, пять новых графиков, соответствие
маршрута пробам и HTTP-данные графиков. В браузере проверены рабочее поле,
локальные настройки, обе шкалы, подписи шагов и J, диапазоны осей,
Save и восстановление схемы. Тип graph_xyz сохранён для совместимости старых файлов.

Прежние схемы без Эксперимента используют совместимый прежний путь расчёта.
Павлуша в этой доработке не менялся.
