# PavSim 0.1.0

Parametric Analysis & Visual Simulation — первый самостоятельный выпуск.

- Визуальный редактор, JSON Save/Load, маршруты связей и файловая библиотека 61 типа.
- Фиксированный шаг, RK4/Euler, П через Усилитель, ПИ/ПД/ПИД, задержки и дискретные элементы.
- Подсистемы и независимые эксперименты со своими часами и итоговой J.
- Пять методов подбора, включая Хука–Дживса; до трёх активных переменных и границы.
- IAE, ISE, время регулирования, перерегулирование и колебательность.
- 1–4 серии, XY и маршрут подбора XY с оценкой.

## Исправления перед выпуском

- Статические файлы ограничены реальным каталогом web/: переходы ..,
  соседние каталоги с общим префиксом и внешние символьные ссылки отклоняются.
- Последний интервал интегрирования при необходимости укорачивается:
  последний отсчёт точно t_end, без превышения. Номинальный h и существующие
  правила дискретной памяти/периодов сохраняются; z^-1 остаётся задержкой
  на один отсчёт. Память обновляется только на выходных отсчётах.
- Некорректные и неконечные временные параметры возвращают HTTP 400.
- Старый JSON для проверки совместимости перенесён в tests/fixtures;
  пользовательские модели не нужны для запуска тестов.
- Обновлены инструкции, ограничения и сведения о зависимостях; добавлен .gitignore.

## Проверка

Проверено на Linux x86_64, CPython 3.12.3, в чистом venv без сторонних
Python-пакетов и PYTHONPATH. Для полного набора нужен Node.js (проверено v18.19.1).
225 тестов проходят без пропусков, smoke-набор проходит, все пять примеров запускаются.
RK4 сопоставлен с аналитическими решениями и проверен на укороченном последнем
интервале. Задержки, дискретные периоды, эксперименты и оптимизация покрыты
регрессиями. Статические проверки, JS harness и браузерные проверки — разные
виды свидетельств, число тестов не заменяет ручную приёмку всех типов блоков.

## Ограничения

Фиксированный шаг, без адаптивного решателя, Xcos-импорта, произвольных
векторных сигналов, 3D и решателя алгебраических петель. Нет произвольной
вложенности подсистем; эксперименты последовательные, вложенный запуск не поддерживается.
Графики хранятся в памяти для последних пяти запусков; Save не сохраняет их
историю или глобальные часы обычной схемы. Локальные часы эксперимента сохраняются.
Сервер предназначен для локального использования, аутентификации нет.
Дополнительные Python-блоки выполняются как доверенный код.

Внутренние имена xcos_mini и graph_xyz сохранены для совместимости.
