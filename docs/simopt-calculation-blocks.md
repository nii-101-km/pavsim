# Расчётные блоки из библиотеки SimOpt

В инструкции используются русские названия интерфейса: выберите **RU**
в верхней панели. Начиная с PavSim 0.1.1 по умолчанию выбран **EN**;
переключение языка не меняет идентификаторы и формат моделей.

Расчётная часть PavSim включает 41 тип, перенесённый из SimOpt, и прежние блоки.
Полная библиотека вместе с экспериментами, оптимизацией и графиками — 61 тип.
Расчёт использует общий решатель Engine (RK4 или Euler), включая внутренние
схемы Subsystem. Оптимизатор SimOpt в этот этап не входит.

## ПИД с входами коэффициентов

Входы сверху вниз: **e, k1, k2, k3**. Единственный выход — **u**.
Все четыре входа должны быть подключены; нулевой коэффициент подаётся
блоком Constant со значением 0. Коэффициенты могут меняться во времени.

Формулы:

- I' = e;
- z' = (e − z) / filter_tau;
- u = k1·e + k2·I + k3·(e − z)/filter_tau.

Это параллельный ПИД с фильтрованной производной ошибки.
`filter_tau` положителен; начальные значения I и z задаются параметрами
`initial_integral` и `initial_filter`. Для точного расчёта выбирайте шаг
существенно меньше постоянных времени схемы, включая filter_tau.
Изменение k2 умножает уже накопленный интеграл ошибки, а не меняет его историю.
ПИ имеет входы e/k1/k2, ПД — e/k1/k3.

Пример `examples/demo_pid_four_inputs.json`: e=1, k1=2, k2=1, k3=0.2,
filter_tau=0.2, нулевые начальные состояния. Ожидается u(t)=2+t+exp(−5t).

## Задержка и дискретные блоки

`transport_delay` — задержка на tau единиц модельного времени, с линейной
интерполяцией истории и initial_value до начала расчёта. tau=0 пропускает
текущий сигнал. Дробная задержка и tau меньше шага поддерживаются.
Прежний `delay` остаётся задержкой на один шаг, z⁻¹.

В SimOpt при tau меньше шага запрос мог попадать позже последней сохранённой
точки истории: генерация выполнялась до записи текущего входа. В новой
реализации текущий вход участвует в интерполяции этого случая.

Период экстраполяторов должен быть не меньше h и кратен h. Производная
`derivative` — обратная разность по шагам; первое значение равно 0.
Шум воспроизводится по seed и удерживается в пределах шага; пробные
вычисления RK4 не потребляют новые случайные значения.

## Передаточная функция и сигналы

Числитель и знаменатель задаются строками коэффициентов по убыванию степени,
например numerator="1", denominator="1,2,1" для 1/(s²+2s+1).
Поддерживаются правильные рациональные функции: степень числителя не выше
степени знаменателя. initial_state — состояния канонической реализации,
а не значения производных выхода. "0" обнуляет все состояния.

У полинома coefficients также перечислены по убыванию степени.
У кусочного сигнала times — абсолютные возрастающие моменты, values —
значения, mode — linear или hold. Для шума sigma — стандартное отклонение.

Это перенос расчётных возможностей, а не импорт файлов Java SimOpt.
Число входов/выходов блоков фиксировано; дополнительные ветви можно собрать
из нескольких сумматоров/разветвителей.

## Проверки

176 тестов проходят. 15 новых поведенческих тестов содержат проверки
всех новых типов, полных рядов сигналов, аналитических решений, двух
решателей, изменяющихся коэффициентов, подсистем, некорректных параметров
и задержек 0 / меньше шага / дробных / кратных шагу.

В браузере отдельно проверены загрузка ПИД, четыре подписанных порта,
запуск, изменение filter_tau, сохранение и восстановление после перезагрузки.
Это не заменяет ручную проверку каждого нового блока. Отдельное окно
рисования графика в этой проверке не проверялось.
